# PSN Store Clone

Clone da interface da **PlayStation Store** feito em **Angular 17** com renderização no servidor (SSR, Express). Projeto de estudo de componentes, rotas e layout.

- `navbar` — barra de navegação;
- `card` — cartão de jogo reutilizável;
- `home` — página principal com a grelha de jogos.

## Executar

```bash
npm install
ng serve                 # desenvolvimento em http://localhost:4200
npm run build            # build com SSR
```
